## 仕組みをひとことで

```
Obsidianで編集（自分のPC）
   ↓  preview_local.bat で見た目を確認
   ↓  git-push.bat で公開
GitHub（kentng111/mysite）に保存
   ↓  自動でサイトを組み立て（2〜3分）
https://snu-o.com/ に反映
```

- サイトの中身はすべて GitHub に保存されています。各PCはその「写し」を持っていて、編集したら GitHub に送り返します。
- 複数のPCで作業するので、**作業前に `get-latest.bat`（最新を取得）**、**作業後に `git-push.bat`（公開）** の2つが基本です。

## ボタン（フォルダ直下の bat ファイル）

| ファイル | 役割 | いつ使う |
|---|---|---|
| `get-latest.bat` | 最新を取得 | 作業を始める前に毎回 |
| `preview_local.bat` | 手元で見た目を確認 | 編集中・公開前 |
| `git-push.bat` | 公開 | 作業が終わったら |

サイトのフォルダ（`C:\Users\（ユーザー名）\myApp\mysite`）を開いてすぐの場所にあります。ダブルクリックで実行し、黒い画面の案内に従ってください。
