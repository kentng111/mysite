# 01 準備するもの

[← 目次](00_目次.md)

新しいPCでサイトの編集・公開ができるようになるまでに、必要なものをまとめています。
**このページは読むだけでOKです。** 実際の作業は次の [02_新しいPCのセットアップ](02_新しいPCのセットアップ.md) で、順番に行います。

---

## 前提

- Windows 10 または Windows 11 のPC
- インターネットにつながっていること
- **Obsidian がインストール済み**であること
- 所要時間：**40分〜1時間**（初回のみ。2回目以降は不要）

> 会社などで管理されているPCでは、ソフトのインストールが制限されていることがあります。途中で「管理者のパスワード」を求められて先に進めない場合は、PCの管理者に相談してください。

---

## 用意するもの（4つ）

### 1. GitHub（ギットハブ）のアカウント
サイトのデータが保管されているインターネット上の場所です。**1人1つ**、無料で作れます。
アカウントを作ったら、サイトの管理者に「招待」してもらいます。招待されないと、データを取得することも公開することもできません。

### 2. Git（ギット）
PCと GitHub の間で、データを受け取ったり送ったりするソフトです。
画面に表示されることはほとんどありません。裏で `get-latest.bat`（最新を取得）や `git-push.bat`（公開）が使います。

### 3. Hugo（ヒューゴ）
書いたページを、ウェブサイトの形に組み立てるソフトです。
公開前に、自分のPCで見た目を確認する（プレビュー）ときに使います。
**バージョン 0.151.0 の extended 版**をそろえます。

### 4. Obsidian（オブシディアン）
ページを書くソフトです。**インストール済み**のため、準備は不要です。

## 用語メモ

手順書の中で出てくる言葉です。

| 言葉 | 意味 |
|---|---|
| エクスプローラー | Windows で、フォルダやファイルを見る画面（黄色いフォルダのアイコン） |
| PowerShell（パワーシェル） | 文字で命令を入力する画面。セットアップのときだけ使います |
| サイトのフォルダ | サイトのデータ一式が入ったフォルダ。名前は `mysite` |
| bat ファイル | ダブルクリックすると決まった処理をしてくれるファイル（例：`git-push.bat`） |
| 公開 | 編集した内容を、インターネット上のサイトに反映すること |
| プレビュー | 公開する前に、自分のPCだけで見た目を確認すること |
