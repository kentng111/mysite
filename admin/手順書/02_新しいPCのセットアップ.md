# 02 新しいPCのセットアップ

[← 目次](00_目次.md)

Obsidian だけが入っているPCを、サイトの編集・公開ができる状態にする手順です。
**上から順番に**進めてください。途中でわからなくなったら、その画面のスクリーンショットを管理者に送ってください。

## 手順0　最初に覚える3つの操作

### (1) エクスプローラーを開く
フォルダやファイルを見る画面です。

- 画面いちばん下のバー（タスクバー）にある、**黄色いフォルダのアイコン**をクリック
- または、キーボードの **Windowsキー（窓のマーク）を押しながら E**

### (2) PowerShell を開く
文字で命令を入力する画面です。この手順書では、ソフトのインストールとデータの取得に使います。

1. 画面左下の **スタートボタン（窓のマーク）** をクリック
2. そのままキーボードで `powershell` と入力
3. 一覧に出てくる **「Windows PowerShell」** をクリック

青または黒い画面が開き、次のような行が表示されます。

```
PS C:\Users\（あなたのユーザー名）>
```

この `>` の後ろに命令を貼り付けて、Enter キーを押すと実行されます。

### (3) 命令をコピーして貼り付ける
この手順書の灰色の枠の中が「命令」です。**手で打たずに、コピーして貼り付けてください。**

1. 灰色の枠の中の文字を、マウスでなぞって選ぶ（Obsidian では枠の右上に出る「コピー」ボタンでもOK）
2. **Ctrl + C** でコピー
3. PowerShell の画面をクリックしてから、**Ctrl + V**（またはマウスの右クリック）で貼り付け
4. **Enter** キーを押す

> 命令は **1行ずつ** 貼り付けて実行してください。実行中は文字が流れます。次の `PS C:\…>` が出てきたら終わりの合図です。

## 手順1　GitHubのアカウントを作る

> すでに GitHub のアカウントを持っている人は、「1-3」から進めてください。

### 1-1. アカウントを作る
1. ブラウザ（Chrome や Edge など）で https://github.com/signup を開く
2. 画面の案内に従って、次の3つを入力
   - **メールアドレス**（ふだん使っているもの）
   - **パスワード**（15文字以上、または数字と小文字を含む8文字以上）
   - **ユーザー名**（半角英数字。例：`miho-snu`。あとで管理者に伝えます）
3. パズルの確認（ロボットではない確認）が出たら、案内どおりに解く
4. 入力したメールアドレスに **数字のコード** が届くので、画面に入力する

### 1-2. ログインできることを確認
https://github.com/ を開いて、右上に自分のアイコンが表示されていればOKです。

### 1-3. 管理者に招待してもらう
1. 管理者に **GitHub のユーザー名** を伝える
2. しばらくすると、GitHub から **「invited you to collaborate on kentng111/mysite」** という件名のメールが届く
3. メールの中の **「View invitation」** をクリック → 開いたページで緑色の **「Accept invitation」** をクリック

> メールが見つからないときは、迷惑メールのフォルダも確認してください。https://github.com/kentng111/mysite/invitations を開いても承認できます。

## 手順2　Gitをインストールする

1. PowerShell を開く（手順0の(2)）
2. 次の命令を貼り付けて Enter

```powershell
winget install --id Git.Git -e
```

3. 次のような質問が出たら、キーボードで **`Y`** を入力して Enter
   ```
   Do you agree to all the source agreements terms?
   [Y] Yes  [N] No:
   ```
4. 画面が暗くなり **「このアプリがデバイスに変更を加えることを許可しますか？」** と出たら **「はい」**
5. **「インストールが完了しました」**（または `Successfully installed`）と出たら完了
6. **PowerShell の画面を右上の × で閉じます**（閉じて開き直さないと、入れた Git が使えません）

### 確認
もう一度 PowerShell を開いて、次を貼り付けて Enter。

```powershell
git --version
```

`git version 2.○○.○` のように表示されればOKです。

> **うまくいかないとき**
> - `winget` が見つからない（「認識されません」と赤い文字が出る）場合：
>   1. ブラウザで https://git-scm.com/download/win を開く
>   2. **「Click here to download」** をクリックしてダウンロード
>   3. ダウンロードしたファイル（`Git-○○-64-bit.exe`）をダブルクリック
>   4. 「許可しますか？」→「はい」
>   5. 以降の画面は、**何も変えずに「Next」を押し続け**、最後に「Install」→「Finish」
>   6. PowerShell を開き直して、上の「確認」を行う

## 手順3　Hugoをインストールする

1. PowerShell を開く
2. 次の命令を貼り付けて Enter

```powershell
winget install --id Hugo.Hugo.Extended -e --version 0.151.0
```

3. 質問や「許可しますか？」が出たら、手順2と同じく `Y` または「はい」
4. 完了したら、**PowerShell を閉じて開き直す**

### 確認

```powershell
hugo version
```

`hugo v0.151.0-○○○○+extended windows/amd64 …` と表示されればOKです。
**「0.151.0」** と **「extended」** の2つが入っているか確認してください。

> **うまくいかないとき（別の入れ方）**
> この方法は **手順4が終わってから** 行います（置き場所のフォルダが手順4でできるため）。
>
> 1. ブラウザで https://github.com/gohugoio/hugo/releases/tag/v0.151.0 を開く
> 2. ページを下にスクロールし、**「Assets」** の見出しを探す
>    （一覧が短いときは、その下の **「Show all ○○ assets」** をクリック）
> 3. 一覧から **`hugo_extended_0.151.0_windows-amd64.zip`** をクリックしてダウンロード
>    （`extended` と `windows-amd64` が両方入っているものです。似た名前が多いので注意）
> 4. エクスプローラーで **「ダウンロード」** フォルダを開く（左側の一覧にあります）
> 5. ダウンロードした zip ファイルを **右クリック →「すべて展開」→「展開」**
> 6. 開いたフォルダの中にある **`hugo`**（または `hugo.exe`）というファイルを右クリック →「コピー」
> 7. 手順4でできたサイトのフォルダ（`mysite`）を開き、何もないところで右クリック →「貼り付け」
>
> これで、プレビュー（手順7）が使えるようになります。この方法では `hugo version` の確認はできないので、手順7で確認してください。

## 手順4　サイトのデータをPCに取得する

1. PowerShell を開く
2. 次の命令を **1行ずつ** 貼り付けて Enter

```powershell
mkdir -Force $HOME\myApp ; cd $HOME\myApp
```

```powershell
git clone https://github.com/kentng111/mysite.git
```

3. 2行目を実行すると、**「Connect to GitHub」** という小さな画面が出ます
   → **「Sign in with your browser」** をクリック
4. ブラウザが開くので、GitHub にログイン（手順1のアカウント）
5. **「Authorize git-ecosystem」**（緑のボタン）をクリック
6. ブラウザに「Authentication Succeeded」と出たら、ブラウザは閉じてOK
7. PowerShell に戻り、文字の流れが止まって `PS C:\…>` が出たら完了

### できたフォルダの場所

```
C:\Users\（あなたのユーザー名）\myApp\mysite
```

これが **「サイトのフォルダ」** です。以降の作業はすべてこのフォルダで行います。

> - 「repository not found」「403」と出た場合：手順1-3の招待の承認が済んでいるか確認してください。
> - 「already exists」と出た場合：すでに取得済みです。そのまま手順5へ進んでください。
> - サイトのフォルダは **OneDrive やデスクトップの中に移動しないでください**（同期とぶつかって壊れることがあります）。

## 手順5　サイトのフォルダをすぐ開けるようにする

### 5-1. サイトのフォルダを開く
1. エクスプローラーを開く
2. 上のほうにある **アドレス欄**（フォルダの場所が書いてある横長の欄）をクリック
3. 次の文字を貼り付けて Enter

```
%USERPROFILE%\myApp\mysite
```

`content`、`admin` などのフォルダと、`git-push.bat` などのファイルが並んでいれば正解です。

### 5-2. 左側の一覧に登録する（クイックアクセス）
1. アドレス欄の左にある **「↑」**（1つ上のフォルダへ）をクリックして、`myApp` フォルダに移動
2. `mysite` フォルダを **右クリック →「クイックアクセスにピン留めする」**

次からは、エクスプローラーの左側にある `mysite` をクリックするだけで開けます。

### 5-3. ファイルの「拡張子」を表示する
画像の名前（`.jpg` など）を正しく扱うために必要な設定です。

- **Windows 11**：エクスプローラー上部の **「表示」→「表示」→「ファイル名拡張子」** をクリックしてチェックを入れる
- **Windows 10**：エクスプローラー上部の **「表示」** タブ →「**ファイル名拡張子**」にチェックを入れる

`git-push` が `git-push.bat` と表示されるようになればOKです。

### 5-4.（おすすめ）ボタンをデスクトップに置く
サイトのフォルダの中の次の3つは、ふだんよく使うボタンです。

| ファイル | 役割 |
|---|---|
| `get-latest.bat` | 最新を取得（作業の前に） |
| `preview_local.bat` | プレビュー（見た目の確認） |
| `git-push.bat` | 公開（作業の後に） |

それぞれ **右クリック →（Windows 11 は「その他のオプションを確認」）→「送る」→「デスクトップ（ショートカットを作成）」** で、デスクトップから使えるようになります。

## 手順6　Obsidianでサイトのフォルダを開く

1. Obsidian を起動
2. 最初の画面が出た場合 → **「フォルダを保管庫として開く」** の「開く」をクリック
   すでに別の保管庫が開いている場合 → 画面左下の **保管庫の名前** をクリック →「**保管庫を管理…**」→「**フォルダを保管庫として開く**」の「開く」
3. フォルダを選ぶ画面で、手順4のサイトのフォルダ（`ユーザー名` → `myApp` → `mysite`）を選び、「フォルダーの選択」
4. **「この保管庫の作者を信頼しますか？」** と聞かれたら →「**作者を信頼してプラグインを有効化**」

> プラグイン（ページを作る機能など）とショートカットキーは、フォルダと一緒に共有されています。開くだけで同じ環境になります。

### 確認
- 左側のファイル一覧に `admin`、`content` が見える
- `layouts` や `themes` は**見えない**（誤って触らないよう隠しています）
- `admin` → `content.base` を開くと、ページの一覧表が表示される

## 手順7　プレビューで確認する

1. サイトのフォルダ（または手順5-4のデスクトップ）の **`preview_local.bat` をダブルクリック**
2. 黒い画面が開き、文字が流れる
3. 数秒後に **ブラウザが自動で開き**、サイトが表示されればOK
   （開かないときは、ブラウザで http://localhost:1313/ を開く）
4. 確認できたら、**黒い画面を右上の × で閉じる**（閉じるとプレビューも終了します）

> 黒い画面に `ERROR: Hugo was not found.` と出た場合は、手順3をやり直してください。
> 「WindowsによってPCが保護されました」と出た場合は、「詳細情報」→「実行」をクリックしてください。

---

## 手順8　名前を登録する

1. **`get-latest.bat` をダブルクリック**
2. 初回だけ、次の2つを聞かれるので入力して Enter
   - **名前**（例：`Miho Shimooka`）… サイトの更新履歴に「誰が更新したか」として残ります
   - **メールアドレス** … GitHub に登録したもの
3. 「**すでに最新です**」と出たら、Enter で閉じる

## セットアップ完了チェック

- [ ] GitHub のアカウントを作り、招待を承認した
- [ ] `git --version` が表示された
- [ ] `hugo version` に 0.151.0 と extended が表示された（または hugo を mysite に置いた）
- [ ] `myApp\mysite` フォルダができ、クイックアクセスに登録した
- [ ] ファイル名拡張子を表示する設定にした
- [ ] Obsidian で mysite を開き、プラグインを有効にした
- [ ] プレビューでサイトが表示された
- [ ] `get-latest.bat` で名前を登録し、「すでに最新です」と出た

すべてチェックできたら、セットアップは完了です。
