# 03 日々の運用

[← 目次](00_目次.md)

## 使うものの場所

| もの | 場所 |
|---|---|
| サイトのフォルダ | エクスプローラー左側の **`mysite`**（セットアップの手順5で登録）<br>場所：`C:\Users\（ユーザー名）\myApp\mysite` |
| 3つのボタン（bat ファイル） | サイトのフォルダを開いてすぐの場所。デスクトップにショートカットを置いた人はデスクトップから |
| ページの中身 | Obsidian の左側の一覧の **`content`** フォルダ（1ページ＝1フォルダ） |
| 手順書 | Obsidian の左側の一覧の **`admin` → `手順書`** |

## 基本の流れ（毎回これだけ）

| | やること | 操作 |
|---|---|---|
| 1 | **最新を取得** | `get-latest.bat` をダブルクリック |
| 2 | **編集** | Obsidian でページを書く・画像を入れる |
| 3 | **確認** | `preview_local.bat` → http://localhost:1313/ |
| 4 | **公開** | `git-push.bat` をダブルクリック → メモを入力 → `y` |
| 5 | **公開後の確認** | 2〜3分後に https://snu-o.com/ を開く（反映されないときは Ctrl+F5） |

### 1. 最新を取得
ほかのPCでの更新を取り込みます。**作業前に毎回**行ってください。忘れると、公開時に内容がぶつかる原因になります。

1. `get-latest.bat` をダブルクリック
2. 黒い画面に「すでに最新です」または「最新になりました」と出たら、Enter キーで閉じる
3. Obsidian を開いて作業を始める

### 2. 編集
Obsidian で編集します。書き方は [04_ページ編集のルール](04_ページ編集のルール.md) を参照してください。保存は自動です。

### 3. 確認
`preview_local.bat` をダブルクリックすると、黒い画面が開き、数秒後にブラウザでサイトが表示されます。黒い画面は、確認が終わるまで**閉じずにそのまま**にしておきます（最小化はOK）。終わったら右上の × で閉じます。

- `preview_local.bat` を起動している間は、保存するたびにブラウザの表示が自動で更新されます。
- プレビューには **非公開（`draft: true`）のページも表示** されます。公開サイトとの違いに注意してください。
- 黒い画面に `WARN` や `ERROR` が出たら、内容を確認します（よくあるものは [05_FAQ](05_FAQ・トラブル対応.md)）。

### 4. 公開
1. `git-push.bat` をダブルクリック
2. 「今回公開される変更」の一覧を確認（`[新規]` `[変更]` `[削除]`）
3. 黄色の注意で「`draft: true` のため表示されません」と出たページは、サイトには載りません（意図どおりなら問題なし）
4. 変更内容のメモを入力（例：`天神の家 追加`）→ Enter
5. 「公開してよろしいですか？」に `y` → Enter
6. 「完了しました」と出れば送信完了。2〜3分でサイトに反映されます

> 公開の進み具合は https://github.com/kentng111/mysite/actions で見られます（緑のチェック＝成功、赤い×＝失敗）。

## 約束ごと

1. **作業前に必ず「最新を取得」、作業後は早めに「公開」**
   変更をPCに溜めたままにしないでください。非公開のまま保存しておきたいページは `draft: true` にして公開すれば、ほかのPCとも共有されます。
2. **同じページを同時に編集しない**
   2人で作業するときは、どのページを触るか先に声をかけてください。
3. **編集するのは `content` の中だけ**
   `layouts`、`assets`、`hugo.toml`、`.github`、`scripts` などのサイトの仕組みは管理者のみが触ります（Obsidian では非表示になっています）。
4. **公開済みページの URL名（`slug`）は変えない**
   変えるとリンクや検索結果が切れます。
5. **困ったら無理に直さず管理者へ**
   エラーの画面をスクリーンショットで送ってください。

## 公開・非公開の切り替え

| したいこと | 操作 |
|---|---|
| ページを公開する | そのページの `draft` を `false`（チェックを外す）にして公開 |
| ページを非公開に戻す | `draft` を `true`（チェックを入れる）にして公開 |
| ページを完全に消す | `content` 内のそのフォルダごと削除して公開 |

> 日本語版と英語版は、それぞれの `draft` で別々に公開・非公開が決まります。

## Obsidian のショートカット

| キー | 動作 | 使う場面 |
|---|---|---|
| `Alt + N` | 新規ページを作成 | 新しい空のノート（`Ctrl + N`）を開いた状態で |
| `Alt + E` | 英語版を作成 | 日本語ページ（`index.md`）を開いた状態で |
| `Alt + X` | 基本の項目（プロパティ）を挿入 | 項目が足りないページで |
| `Alt + Z` | 編集画面の表示切り替え（ソース表示） | 細かい記号を確認したいとき |

## 管理表

`admin/content.base` を開くと、全ページの一覧表が見られます。

| 表示 | 内容 |
|---|---|
| ページ一覧 | フォルダごとに日英・公開状態・URL・サムネイルの有無 |
| 要確認 | URL名・タイトル・サムネイルが足りないページ |
| 画像 | フォルダごとの画像 |
| 色 | 各ページの `color` |

公開前に「要確認」が空になっているか見ておくと安心です。
