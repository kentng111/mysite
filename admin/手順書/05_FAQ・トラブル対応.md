# 05 FAQ・トラブル対応

[← 目次](00_目次.md)

困ったときは、まずこのページを確認してください。解決しない場合は、**黒い画面やエラーのスクリーンショット**を管理者に送ってください。

---

## セットアップ

### Q. PowerShell に赤い文字が出た
命令が実行できなかったという意味です。次を確認してください。
- 命令を**手で打たず、コピーして貼り付けたか**（1文字違うだけで動きません）
- **1行ずつ**貼り付けたか
- ソフトを入れた直後なら、**PowerShell を閉じて開き直したか**

それでもだめな場合は、赤い文字の部分のスクリーンショットを管理者に送ってください。

### Q. 「'winget' は認識されません」と出た
PCに winget（ソフトを入れる仕組み）がありません。手順書02の各手順にある「うまくいかないとき」の方法で入れてください。

### Q. データの取得（git clone）で「repository not found」「403」と出た
GitHub の招待を承認していないか、別のアカウントでログインしています。手順書02の「1-3」を確認してください。
別のアカウントでログインしてしまった場合は、スタートボタン →「資格情報マネージャー」→「Windows 資格情報」→ `git:https://github.com` を削除してから、もう一度取得してください。

### Q. サイトのフォルダがどこにあるかわからなくなった
エクスプローラーのアドレス欄に `%USERPROFILE%\myApp\mysite` と入力して Enter を押すと開きます。

## 公開（git-push.bat）

### Q. 「他の人の更新と内容がぶつかりました」と出た
同じファイルをほかのPCでも変更していて、自動ではまとめられなかった状態です。
- **何も公開されていません**。自分の変更も消えていません。
- 自分で直そうとせず、**そのままの状態で管理者に連絡**してください（直し方は [06_管理者向け](06_管理者向け.md)）。
- 予防：作業前に必ず `get-latest.bat`、同じページを同時に編集しない。

### Q. 「送信に失敗しました」と出た
- インターネット接続を確認して、もう一度 `git-push.bat` を実行してください。
- ブラウザで GitHub のログイン画面が出たら、招待を受けたアカウントでログインしてください。
- 「Permission denied」「403」と出る場合は、リポジトリへの招待が済んでいません。管理者に確認してください。

### Q. 「公開する変更はありません」と出た
変更が保存されていないか、すでに公開済みです。Obsidian で編集内容が残っているか確認してください。

### Q. 公開したのにサイトに反映されない
順に確認してください。
1. 2〜3分待ってから **Ctrl + F5**（ブラウザの再読み込み）
2. そのページの `draft` がオフ（false）になっているか
3. https://github.com/kentng111/mysite/actions で、最新の行が緑のチェックか
   - 黄色い丸：作業中なので待つ
   - 赤い×：公開に失敗。管理者に連絡

### Q. 間違えて公開してしまった
- 内容の誤り：直して、もう一度公開すれば上書きされます。
- 公開してはいけないページ：`draft` をオンにして、すぐ公開してください。
- 過去の状態に丸ごと戻したい：管理者に連絡してください（履歴から戻せます）。

## 取得（get-latest.bat）

### Q. 「取得に失敗しました」と出た
- インターネット接続を確認して再実行してください。
- 続く場合は、自分の変更とほかの人の変更がぶつかっている可能性があります。そのまま管理者に連絡してください。

### Q. 名前とメールアドレスを間違えて登録した
PowerShell で次を実行して、登録し直してください。

```powershell
git config --global user.name "正しい名前"
git config --global user.email "正しいメールアドレス"
```

## プレビュー（preview_local.bat）

### Q. 黒い画面に「ERROR: Hugo was not found.」と出る
Hugo が入っていないか、認識されていません。[02_新しいPCのセットアップ](02_新しいPCのセットアップ.md) の手順3をやり直してください。winget で入れた場合は、PCを再起動すると直ることもあります。

### Q. ブラウザで http://localhost:1313/ が開けない
- 黒い画面が開いたままになっているか確認（閉じるとプレビューも止まります）。
- すでに別の黒い画面でプレビューを起動している場合は、そちらを使うか、全部閉じてから起動し直してください。
- 黒い画面に `ERROR` が出ている場合は、直前に編集したページの項目（`---` の間）の書き方が崩れていることが多いです。`:` の後のスペースや `"` の閉じ忘れを確認してください。

### Q. 黒い画面に「リンク先のページが見つかりません」と出た
本文のリンク先のページが存在しません（削除した・名前を変えた）。表示されているファイルのリンクを直してください。

### Q. プレビューでは見えるのに、公開サイトに出ない
プレビューには非公開（`draft: true`）のページも表示されます。`draft` を確認してください。

## 画像

### Q. 画像が表示されない（プレビューでは見える／公開サイトだけ見えない）
ファイル名の **大文字・小文字** が本文の記述と一致していない可能性が高いです（例：ファイルは `Photo.JPG`、本文は `photo.jpg`）。ファイル名を半角小文字にそろえ、本文も合わせてください。

### Q. 画像が表示されない（プレビューでも見えない）
- 画像がページと**同じフォルダ**にあるか
- ファイル名にスペースや日本語が入っていないか（半角英数字に変更）

### Q. 一覧にサムネイルが出ない
サムネイル画像の名前が `cover_` で始まっていません。名前を変えてください（例：`cover_main.jpg`）。

## Obsidian

### Q. Alt + N / Alt + E が効かない
- 「制限モード」がオンになっている可能性があります。設定 →「コミュニティプラグイン」→「制限モードをオフにする」→ Templater がオンか確認してください。
- `Alt + N` は**新しい空のノート**で、`Alt + E` は**日本語ページ（index.md）**で実行してください。それ以外では案内が出て止まります。

### Q. `layouts` や `themes` などのフォルダが見えない
意図どおりです。サイトの仕組みのファイルは、誤って触らないよう非表示にしています。

### Q. 管理表（content.base）が開けない・表示がおかしい
Obsidian を最新版に更新してください（Bases は比較的新しい機能です）。

## その他

### Q. ページの URL を変えたい
公開済みのページは原則変えないでください。どうしても必要な場合は管理者に相談してください。

### Q. 猫を出したくない
そのページの `neko` をオフ（false）にしてください。

### Q. Mac で作業したい
bat ファイルが使えないため、この手順書のままでは作業できません。管理者に相談してください。
