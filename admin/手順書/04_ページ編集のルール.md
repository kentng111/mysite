# 04 ページ編集のルール

[← 目次](00_目次.md)

## ページの構成

1ページ＝`content` の中の1フォルダです。

```
content/
└─ tenjin-house/            ← フォルダ（URL名と同じにしておくと管理しやすい）
   ├─ index.md              ← 日本語ページ
   ├─ index.en.md           ← 英語ページ（あれば）
   ├─ 01.jpg                ← 本文の画像（1枚目が自動でサムネイルになる）
   └─ 02.jpg
```

| ページ | URL |
|---|---|
| 日本語 `index.md` | `https://snu-o.com/（slug）/` |
| 英語 `index.en.md` | `https://snu-o.com/en/（slug）/` |

---

## 新しいページを作る

1. Obsidian で `Ctrl + N`（新しい空のノート）
2. `Alt + N`
3. **タイトル**を入力（日本語OK）→ **URL名**を入力（半角英小文字・数字・ハイフン。例：`tenjin-house`）
4. `content/tenjin-house/index.md` が、必要な項目入りで作られます
5. 画像をそのフォルダに入れ（Obsidian の左の一覧へドラッグ）、`Alt + I` で挿入しながら本文を書く

> URL名は公開後に変えないでください。最初に決める名前は短く、内容がわかるものにしてください。

---

## 項目（プロパティ）

ページ上部の `---` で囲まれた部分です。

| 項目 | 内容 | 例 |
|---|---|---|
| `title` | ページのタイトル | `天神の家` |
| `slug` | URL名。**公開後は変えない** | `tenjin-house` |
| `description` | 一覧（画像＋情報ビュー）に出す紹介文。空なら本文の冒頭が出る | `天神の住宅リノベーション` |
| `sort_title` | タイトル順に並べるときの読み。空ならタイトルで並ぶ | `てんじんのいえ` |
| `tags` | タグ（複数可）。一覧の絞り込みに使う | `house` |
| `draft` | チェックあり（true）＝非公開 / なし（false）＝公開 | |
| `color` | 画像がないときのカードの色 | `"#2C5159"` |
| `year` | 年月 | `2026-11` |
| `index` | 並び順の番号（文字列として並ぶので桁をそろえる） | `p012` |
| `neko` | ページ下で猫が歩くかどうか | |
| `thumbnail` | サムネイルにする画像の名前。空なら本文の1枚目（`Alt + T` で設定） | `05.jpg` |
| `thumbnail_position` | サムネイルを正方形に切り抜くときに見せる位置（`Alt + T` で設定） | `top` |

## 画像

### 基本の流れ（3ステップ）
1. **画像をページのフォルダに入れる**
   エクスプローラーから、Obsidian の左のファイル一覧の**そのページのフォルダ**へドラッグします。
   （エクスプローラーで直接フォルダに入れても同じです）
2. **入れたい位置にカーソルを置いて `Alt + I`**
   フォルダ内の画像の一覧が出るので選びます（`［サムネイル］` `（使用済み）` の目印つき）。
3. **完了**
   - 名前が半角英数字でない画像（`IMG 0012.JPG`、`Pasted image ….png` など）は、整えた名前を提案されるので Enter。名前の変更と同時にリンクも自動で直ります。
   - **英語版（日本語版）にも、同じ順番の位置に自動で入ります。** 文章のどこに置くかだけ、必要に応じて調整してください。

### 日英で画像の位置をそろえるしくみ
- 日本語版と英語版は、**画像の枚数と並び順を同じにする**ルールです（文章は言語ごとに自由）。
- `Alt + I` で入れれば、自動で両方に入ります。
- 手で消したり並べ替えたりしてずれたときは、正しいほうのページを開いて **`Alt + S`** を押すと、もう一方の画像の並びがそろいます（文章はそのまま残ります）。
- ずれていると、プレビューのページ上部に「⚠ 画像の並びが〜版と違います」と表示されます（公開サイトには出ません）。

### ファイル名のルール
- **半角英数字**にする（`Alt + I` が自動で整えます）
- **拡張子の大文字・小文字まで、本文の記述と完全に一致させる**
  Windows では `photo.JPG` と `photo.jpg` が同じ扱いですが、公開サイトでは別物になり、画像が表示されなくなります（`Alt + I` を使えば自動でそろいます）。

### サムネイル（一覧に出る画像）
- **何もしなければ、本文の1枚目の画像**がサムネイルになります。
- 別の画像にしたいとき、または切り抜く位置（上・下・左・右）を変えたいときは、ページを開いて **`Alt + T`** → 画像を選ぶ → 見せる位置を選ぶ。
- 本文に載せない画像もサムネイルにできます（フォルダに入れておけば `Alt + T` の一覧に出ます）。
- 英語版は、日本語版と同じサムネイルを自動で使います。
- このサムネイルは、SNS や LINE でページの URL を共有したときに表示される画像にもなります。
- 以前のルール（名前が `cover_` で始まる画像）も引き続き使えます。

### 大きさ
- 写真は **JPEG** 推奨（PNG は容量が大きくなりがち）
- 長辺 **3000px 以下** が目安。公開時に長辺 2000px まで自動で縮小されます（手元の元画像はそのまま）

### 本文での形

```markdown
![](01.jpg)
![外観|400](01.jpg)       ← 幅400pxで表示（説明の後ろに |幅）
```

- 画像は画面の大きさに合わせて自動で縮み、全体がはみ出さずに表示されます。
- 1行に1枚、前後に空行を入れてください（`Alt + I` は自動でそうなります）。

## ページ間のリンク

### 書き方
Obsidian で `[[` と入力 → リンクしたいページの `index` を選ぶと、次の形で入ります。

```markdown
[お問い合わせ](../contact/index.md)
```

- `[ ]` の中は表示される文字です。`index` のままにせず、わかりやすい言葉に書き換えてください。
- 公開サイトでは自動で正しいURLに変換されます。
- 英語ページからのリンクは、相手の英語版に自動でつながります（英語版がない場合は日本語版へ）。
- リンク先のページ名やフォルダ名を Obsidian で変えると、リンクも自動で書き換わります。

### やってはいけない書き方
- `https://snu-o.com/contact/` のような直書き（英語版やプレビューで正しく動かない）
- `[[contact]]` の形（Obsidian の設定上は出ませんが、手で書かないでください）

### 外部サイトへのリンク

```markdown
[Google](https://www.google.com/)
```

外部リンクは新しいタブで開きます。

## 英語版を作る

1. 日本語ページ（`index.md`）を開く
2. `Alt + E` → 英語のタイトルを入力
3. 同じフォルダに `index.en.md` ができ、共通の項目（タグ・色・年月・番号）と画像の行がコピーされます
4. 英語の本文を書く。画像は日本語版と共通です

> 英語版の `draft` は日本語版とは別です。英語版を公開するときは、英語版の `draft` もオフにしてください。
> タグを変えたときは、日英両方のページで変えてください。

## 本文の書き方メモ

| したいこと | 書き方 |
|---|---|
| 見出し | `#### 見出し`（ページタイトルより小さい `####` 以下を推奨） |
| 改行 | そのまま改行すれば、サイトでも改行されます |
| 段落を分ける | 空行を1行入れる |
| 太字 | `**太字**` |
| 箇条書き | `- 項目` |
